## 运行结构与项目数据

工作台在本机浏览器内执行，入口是 `web/index.html`。Windows 启动器和 macOS 应用打开相同的单文件 HTML。解析、预览与打包在浏览器中完成。真正运行量化计算、容器评测或 MDArena 过程评审时，所需软件、镜像与模型凭据由评测环境提供。

| 模块与入口 | 数据流 |
| --- | --- |
| `Chemistry.parse(filename, raw)` | `web/chemistry.js` 读取 GJF、COM、XYZ，返回有序原子、计算参数、源文本及警告。 |
| `Studio.fresh / checked` | `web/core.js` 创建 v1 项目，恢复时从保存的源文本重新解析结构并校验字段。 |
| `ChemResults.parse / AnswerBook.apply` | `web/results.js` 列出每个计算段可用的物理量。`web/answer-book.js` 把选中项写入项目。 |
| `Studio.prepare / Studio.zip` | 导出前校验并汇集题面、规则及答案。适配器生成“文件路径到文本”的映射，再写成 ZIP。 |

项目 JSON 中，`structure.raw` 保存原始输入，`settings` 保存题目实际采用的参数，`kindData` 和 `profileData` 分别保存题型和框架选项。`grading` 保存评分模式、规则、参考项和来源。单值题沿用 `expected` 与 `tolerance`，由 `AnswerBook.compile` 统一转换为评分输入。

浏览器使用 `localStorage` 保存草稿。界面语言是独立于项目数据的本机偏好，切换语言时，用户填写的文本和计算日志保留原语言。项目 JSON 可跨机恢复，包含私有答案。选手获得框架公开输入，其中 `structure.xyz` 是规范坐标，`source/` 保留原件，`calculation.json` 并列记录原始设置和有效设置。应按其中的 `settings` 作答，直接运行原件会使用原路由。

## 结构解析与参考答案

输入端接受 UTF-8 文本。Gaussian 输入表单解析第一计算步的显式笛卡尔坐标与路由，识别方法、基组、溶剂模型、电荷和多重度；Bohr 坐标换算为 Å。Link1 后续步骤与 Gen/GenECP 等附加输入保留于原文。XYZ 支持单帧和带 `Properties` 的扩展格式。普通 XYZ 缺少计算条件时应在表单补齐；多帧轨迹应先选定目标帧。

`ChemResults.parse(filename, text)` 通过输出特征识别程序，返回 `{program, jobs}`。各段分别保存终止状态、优化状态、可用性质与警告。电子能以 Eh 表示，振动波数以 cm⁻¹ 表示，最终坐标以 Å 表示。能量和热化学量分别列出，带温度的结果可按标签选取。ORCA 沿用原模式号，Gaussian 按输出次序从 1 编号，二者均保留负频。

| 写入环节 | 校验与记录 |
| --- | --- |
| 作业段与单位 | 选正常结束的段，匹配评分字段类型及单位。ORCA 合并输出若只在末尾报告终止，可导入早期子步的独立完整日志。 |
| 完整构型 | 校验原子数与元素顺序。优化题采用日志坐标时需有明确收敛标记，也可导入出题人已确认的参考 XYZ。 |
| 来源与更新 | 保存文件名、程序、作业段、性质、单位及从 1 开始的行号。替换输入结构会移除先前绑定的答案和来源。 |

来源随私有答案导出。公开补充材料会原样交给选手；导出校验可发现与参考来源同名的附件，改名附件和原始输入中的内容仍需作者审阅。复现导入可搭配使用 `examples/water-seed.xyz` 与 `examples/orca-water.out`，后者为合成格式示例。

## 评分算法与四种导出格式

`web/rubrics.js` 同时提供浏览器规则校验和各框架复用的 Python 评分器。v1 规则含 1–64 个字段，每项定义唯一标识、度量、单位、非负容差和正权重。误差小于或等于容差即取得该项全部权重。缺项、类型错误或超差的项目得零，总分为所得权重除以总权重。

数值预设使用绝对误差；自定义规则还可用相对误差，分母为参考值的绝对值，零参考只接受精确零。构型预设使用等权原子的 RMSD，默认阈值 0.10 Å。算法按输入顺序对应原子，平移质心后用四元数求最佳正旋转，保留镜像差异。单一 RMSD 项提交 `answer.xyz`，其余情况提交 `answer.json`。混合题的坐标字段为包含 `element,x,y,z` 的对象数组。

| 导出目标 | 答卷位置与框架成绩 |
| --- | --- |
| ASI-Bench Chemistry | 答卷在 `results/`。默认满分 100，分项写入 `ScoreDetail.details`。 |
| MDArena | 答卷在 `/app/outputs/`，另交 `/app/final_answer.txt`。Reward Kit 按权重生成正确性成绩，过程评审单列。 |
| Terminal-Bench-Science | 答卷在 `/app/outputs/`。全部通过才上报奖励 1，否则为 0；`metrics.json` 保留加权分与明细。 |
| Harbor Adapters 与 Harbor-Index | 本地候选任务同样读取 `/app/outputs/`，直接上报 0–1 的加权分。正式收录需按上游流程完成。 |

例如能量占 2 份、构型占 3 份，只有构型达标时，独立评分报告的 `score` 为 0.6，`passed` 为 false。此时 ASI 默认给 60 分，Terminal-Bench-Science 的正式奖励为 0，两个结果对应不同的评分约定。

## 扩展接口与发布验证

**新增题型。** 在「导入类型定义」中加载 `examples/bond-distance.task-type.json`。定义以 `id` 和 `name` 标识题型，用 `instructions` 指定题面，`fields` 描述公开字段。字段支持 text、textarea、number、select，select 需提供 options。需要自动计算答案时，可参照 `web/measurement.js` 的内置键长实现。Harbor 独立参考解可提供 Python 函数 `solve(inputs)`，从输入目录计算并返回以评分字段为键的字典。

**新增规则。** AI 可按照 `docs/rubrics.md` 生成规则 JSON。界面导入后，由作者绑定私有参考值。扩充新的度量时，应同步更新 `Rubrics.validate`、参考值校验、Python 误差函数和导出题面对度量的描述，补上达标、未达标与缺项用例。单独增加字段或调整权重可复用现有度量。

在本题评分包内运行下列命令。报告写入标准输出，包含每项误差、权重和判定。退出码 0 表示全部通过，1 表示已批改但有未达标项，2 表示参数或参考配置有误。

```sh
python grade.py submission.json private-reference.json > score.json
```

在源码根目录执行测试和构建。开发测试需要 Node.js 和 Python 3.11+。Windows 完整打包使用 .NET Framework C# 编译器；在 macOS 或 Linux 构建 macOS 包时，将目标改为 `mac`。

```sh
node --test tests/*.test.cjs
python tools/build.py --target all
node tools/build-grader.cjs
```

当前发行版已有 38 项自动测试通过，并在 Windows 完成离线界面和启动器验收。macOS 已校验包结构、启动权限和页面内容，仍需实机启动验证。完整 Harbor 容器运行与 MDArena 在线过程评审尚待验证。
